# CodeAlpha_Chatbot 🤖

## Python Programming Internship — CodeAlpha
**Task 4: Basic Chatbot**

A simple rule-based chatbot built in Python. It recognizes common phrases
(greetings, small talk, thanks, farewells) and responds with predefined
replies.

## Features
- Recognizes greetings, "how are you," thanks, name questions, help requests,
  and goodbyes
- Randomized replies within each category for more natural variety
- Graceful exit when the user says "bye" (or similar)
- Falls back to a default response for unrecognized input

## Key Concepts Used
- `if-elif` logic (via dictionary-based intent matching)
- Functions
- Loops
- Input/output handling

## How to Run
```bash
python3 chatbot.py
```

## Example Conversation
```
========================================
SIMPLE RULE-BASED CHATBOT
========================================
Type 'bye' to end the conversation.

You: hello
Bot: Hi there!
You: how are you
Bot: I'm fine, thanks! How about you?
You: bye
Bot: Goodbye!
```
